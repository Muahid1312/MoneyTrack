# Reference mapping

The reference is Realbyte’s Money Manager Expense & Budget for Android. Google Play and the official help center returned HTTP 403 from this environment. The owner has no screenshots to supply. For entry, the independently published Android screenshot from November 2023 provides a direct comparison. A separate companion tool tested on Android Money Manager 4.13.0 documents red expense and blue income controls, three posting types, and daily totals. MoneyTrack supplies its own fonts, Material icons, theme and artwork. [Official listing](https://play.google.com/store/apps/details?id=com.realbyteapps.moneymanagerfree) · [Android 4.13.0 companion notes](https://github.com/Dr-K-Alvi/money-manager-pc-entry/tree/78f52a7b018e5b5a146c391ee0879853b95623f0) · [Study, slide 3](https://github.com/tdimk2023p/final-project-donataVD/blob/0cf350b8edeb453e38963c481cd02cfbb1338cfc/Donata%20Yulvida_Presentasi%20FP.pptx)
