# Reference mapping

The reference is Realbyte’s Money Manager Expense & Budget for Android. Google Play and the official help center returned HTTP 403 from this environment. Current screenshots were requested. For entry, the independently published Android screenshot from November 2023 provides a direct comparison. MoneyTrack supplies its own fonts, Material icons, theme and artwork. [Official listing](https://play.google.com/store/apps/details?id=com.realbyteapps.moneymanagerfree) · [Study, slide 3](https://github.com/tdimk2023p/final-project-donataVD/blob/0cf350b8edeb453e38963c481cd02cfbb1338cfc/Donata%20Yulvida_Presentasi%20FP.pptx)
