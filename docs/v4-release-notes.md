# MoneyTrack 4.0 Phase 1 development notes

Managed Funds adds an independent ledger for money entrusted by another person. Open **More → Managed Funds** to create a fund, receive funding, record itemized purchases, allocate a personal advance and track direct or fund-paid reimbursements. The overview also shows available entrusted cash and the amount available after outstanding advances. The purchase record contains merchant refunds, receipt preview and replacement, and auditable corrections.

Phase 2 covers shopping lists and reusable templates, money returns, settlement, carry-forward, cancellation and completion, and report previews and exports. Phase 3 covers personal transaction templates, reconciliation, full localization and release preparation. This checkpoint uses the existing application version. A release version will be assigned during release preparation.
